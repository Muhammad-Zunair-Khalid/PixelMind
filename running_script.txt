Yes, every time you start fresh here's the exact order:

**1. Start Docker Desktop first** (from Start menu, wait for whale icon in taskbar to stop animating)

**2. Start containers:**
```powershell
cd "C:\Users\User\OneDrive\4th Sem ALL material\Software Engineering\Project\smart_gallery"
docker compose up -d
```

**3. Start backend (Terminal 1):**
```powershell
.venv\Scripts\activate
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

**4. Start frontend (Terminal 2):**
```powershell
cd frontend
python -m http.server 5500
```

**5. Open browser:**
```
http://localhost:5500/login.html
```

---

Save this as a cheatsheet. The order matters — Docker must be running before uvicorn, and both terminals must stay open while you work.
